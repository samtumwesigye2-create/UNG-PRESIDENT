# UNG-PRESIDENT National Security Council Workspace

Dedicated NSC operations are separated from Staff Admin.

**Staff Admin:** personnel, presidential access/scheduling, executive workflow, appointments, finance/treasury administration, and foreign-affairs administration.

**NSC:** presidential national-security briefings; NSC meetings/agendas; interagency security coordination; presidential security directives and implementation tracking; Situation Room/crisis records; analytical reports/policy options; leader/summit preparation; authorized security communications.

**Access:** `/nsc` permits authenticated `admin`, `national_security`, and `nsc` roles. Records support restricted, confidential, secret, and top-secret classification metadata and remain outside ordinary Staff Admin lists.
